# 深層学習とニューラルネットワーク

深層学習（Deep Learning）は、層を何段も重ねたニューラルネットワークを使う機械学習の手法です。
「深層」とは、ネットワークが多くの隠れ層（hidden layer）を持つことを指します。

## ニューラルネットワークの構造

- 入力層（Input Layer）: データを受け取る
- 隠れ層（Hidden Layer）: 特徴を取り出し、変換する
- 出力層（Output Layer）: 予測結果を出す

活性化関数は、層と層の間に非線形な変換を入れ、複雑なパターンを学べるようにします。
代表的な活性化関数は、ReLU（Rectified Linear Unit）、Sigmoid、Tanh です。

## 学習の仕組み

学習には誤差逆伝播法（Backpropagation）を使います。
損失関数の勾配を連鎖律で出力側から順に計算し、各層の重みを更新します。

## 過学習とその対策

過学習（Overfitting）とは、モデルが訓練データに合わせすぎて、未知のデータでの性能が落ちる現象です。
訓練データの損失は下がり続けるのに、検証データの損失が上がり始めたら過学習のサインです。

対策には次のものがあります。

- ドロップアウト（Dropout）: 学習中にランダムにニューロンを無効にする
- L1 / L2 正則化: 重みが大きくなりすぎないようにペナルティを与える
- バッチ正規化（Batch Normalization）: 各層の入力の分布をそろえる
- 早期終了（Early Stopping）: 検証データの損失が悪化し始めたら学習を止める
- データ拡張（Data Augmentation）: 学習データを変形して水増しする
