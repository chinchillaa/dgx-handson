# 機械学習入門

機械学習とは、データからパターンを学習して予測や分類を行う人工知能の一分野です。
従来のプログラミングではルールを人が書きます。機械学習では、ルールをデータから自動で見つけます。

## 機械学習の 3 つの種類

### 教師あり学習（Supervised Learning）

入力と正解ラベルの組を学習データとして使い、新しい入力に対する出力を予測します。
代表的なアルゴリズムは、線形回帰、決定木、ニューラルネットワークです。
用途の例は、分類（スパムメールの検出）や回帰（住宅価格の予測）です。

### 教師なし学習（Unsupervised Learning）

正解ラベルを使わずに、データの構造やパターンを見つけます。
代表的なアルゴリズムは、k-means クラスタリングと主成分分析（PCA）です。
用途の例は、顧客のグループ分け（セグメンテーション）や異常検出です。

### 強化学習（Reinforcement Learning）

エージェントが環境とやり取りしながら、得られる報酬が最大になる行動の選び方（方策）を学びます。
代表的なアルゴリズムは、Q 学習と PPO です。
用途の例は、ゲームの対戦やロボットの制御です。
