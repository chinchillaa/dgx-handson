Section 1

線形回帰：最もシンプルな「予測関数」

線形回帰は、入力 $x$ から出力 $y$ を予測する最もシンプルな関数です。 「線形（linear）」とは、入力と出力の関係が直線で表せることを意味します。

例として、「部屋の広さ（m²）から家賃（万円）を予測する」問題を考えます。 データを散布図に描いたとき、おおよそ直線に乗っているなら線形回帰が使えます。

モデルの定義

$$ \hat{y} = wx + b $$
$x$入力（例：部屋の広さ）
$\hat{y}$予測値（例：予測家賃）
$w$重み（weight）— パラメータ①
$b$バイアス（bias）— パラメータ②

学習とは $w$ と $b$ の値を「データに合うよう」自動で決める 作業です。 モデルの構造（直線）は人間が決め、パラメータの値はデータから決まります。

コード例 — データ生成と初期予測 
import numpy as np
import matplotlib.pyplot as plt

# 実行時間: 数秒

# ── データ生成 ──────────────────────────────────────
# 真のモデル: y = 2x + 1 にノイズを乗せる
np.random.seed(42)
x = np.linspace(0, 10, 50)
y_true = 2 * x + 1
y = y_true + np.random.randn(50) * 2   # 観測値（ノイズあり）

# ── 初期パラメータでの予測 ──────────────────────────
w, b = 0.0, 0.0   # 初期値はゼロ
y_pred = w * x + b

print(f"初期パラメータ: w={w}, b={b}")
print(f"予測値の例: {y_pred[:5]}")   # すべて 0.0 — まったく予測できていない
出力
初期パラメータ: w=0.0, b=0.0
予測値の例: [0. 0. 0. 0. 0.]

パラメータが $w=0, b=0$ のままでは、予測値がすべて 0 になり何も予測できていません。 次の Section 2 で、予測が「どれだけ外れているか」を数値で測ります。

Section 2

損失関数：「外れ具合」を数値にする

予測値 $\hat{y}$ と正解値 $y$ の「ずれ」を1つの数値にまとめたものが 損失関数（loss function） です。 損失が大きいほど予測は外れており、小さいほど予測は当たっていることを示します。

回帰問題でよく使われるのは平均二乗誤差（MSE: Mean Squared Error）です。 「ずれを二乗して平均をとる」だけのシンプルな計算です。

なぜ「二乗」するのか？

  • ずれにはプラスとマイナスがあるので、単純に合計すると打ち消し合ってしまいます
  • 二乗するとすべてプラスになり、大きなずれほど強いペナルティを与えられます
  • 二乗は微分しやすいので、Section 3 の勾配降下法と相性が良くなります

MSE の定義

$$ L(w, b) = \frac{1}{N} \sum_{i=1}^{N} \left( y_i - \hat{y}_i \right)^2 = \frac{1}{N} \sum_{i=1}^{N} \left( y_i - (wx_i + b) \right)^2 $$
$N$データ点の総数
$y_i$$i$ 番目の正解値
$\hat{y}_i$$i$ 番目の予測値 $= wx_i + b$
$L(w,b)$損失（これを小さくすることが「学習」の目的）
コード例 — MSE の計算 
def mse_loss(y_true, y_pred):
    """平均二乗誤差（MSE）を計算する"""
    return np.mean((y_true - y_pred) ** 2)

# 初期パラメータ（w=0, b=0）での損失
loss_init = mse_loss(y, y_pred)
print(f"初期損失 (w=0, b=0):   {loss_init:.2f}")

# 真のパラメータ（w=2, b=1）での損失
y_pred_true = 2 * x + 1
loss_true = mse_loss(y, y_pred_true)
print(f"真のパラメータの損失:    {loss_true:.2f}")   # ノイズ分だけ残る
出力
初期損失 (w=0, b=0): 145.37
真のパラメータの損失: 3.62

真のパラメータ（$w=2, b=1$）では、損失が初期値（$w=0, b=0$）の 145.37 から 3.62 まで小さくなります。 ノイズがあるため、真のパラメータでも損失は 0 になりません。 「損失を最小化するパラメータを探す」ことが学習のゴールです。

概念図：損失の「地形」

$w$ と $b$ の値を変えると、損失 $L$ の値も変わります。このとき「$L$ は $w$ と $b$ の関数である」と言います。
$L$ をグラフに描いたものが お椀型の曲面になったとします（曲線ではなく曲面です）。
お椀の底（最小値）の位置が、「最もデータに合ったパラメータ」です。

学習とは、現在地から底（損失最小）に向かって少しずつ動くことです

Section 3

勾配降下法：「坂を下る」ようにパラメータを更新する

損失関数のお椀の底を求めるには、 「今いる場所の傾き（勾配）を計算して、坂を下る方向に少し移動する」 を繰り返します。この手続きが 勾配降下法（Gradient Descent） です。

「どのくらいの歩幅で移動するか」を決める定数が 学習率（learning rate） $\alpha$ です。 学習率が大きすぎると底を飛び越え、小さすぎると収束が遅くなります。

勾配の計算（MSE の偏微分）

損失 $L$ が $w$ と $b$ それぞれに対してどのくらい変化するかを求めます。この「変化の割合」が勾配です。

$$ \frac{\partial L}{\partial w} = -\frac{2}{N} \sum_{i=1}^{N} x_i \left( y_i - \hat{y}_i \right) $$ $$ \frac{\partial L}{\partial b} = -\frac{2}{N} \sum_{i=1}^{N} \left( y_i - \hat{y}_i \right) $$

導出は気にしなくて大丈夫です。「誤差 $(y_i - \hat{y}_i)$ が大きいほど勾配も大きい」という直感だけ押さえてください。

パラメータ更新則

勾配の反対方向（損失が下がる方向）に学習率 $\alpha$ だけ移動します。

$$ w \leftarrow w - \alpha \frac{\partial L}{\partial w} $$ $$ b \leftarrow b - \alpha \frac{\partial L}{\partial b} $$

この更新を数百〜数千回繰り返すと、パラメータが少しずつ「正解」に近づいていきます。 これが「学習」の正体です。

コード例 — NumPy で勾配降下法を手実装 
import numpy as np
import matplotlib.pyplot as plt

# 実行時間: 約5秒

# ── データ生成 ──────────────────────────────────────
np.random.seed(42)
x = np.linspace(0, 10, 50)
y = 2 * x + 1 + np.random.randn(50) * 2   # 真: w=2, b=1

# ── 初期化 ──────────────────────────────────────────
w, b = 0.0, 0.0
alpha = 0.01   # 学習率
n_epochs = 300 # 更新回数
N = len(x)

history = []   # 損失の記録

# ── 勾配降下ループ ────────────────────────────────────
for epoch in range(n_epochs):
    # 1. 予測
    y_pred = w * x + b

    # 2. 損失の計算
    loss = np.mean((y - y_pred) ** 2)
    history.append(loss)

    # 3. 勾配の計算（偏微分）
    dw = -2 / N * np.sum(x * (y - y_pred))
    db = -2 / N * np.sum(y - y_pred)

    # 4. パラメータの更新
    w = w - alpha * dw
    b = b - alpha * db

    if epoch % 50 == 0:
        print(f"Epoch {epoch:3d} | loss={loss:.4f} | w={w:.4f} | b={b:.4f}")

print(f"\n最終結果: w={w:.4f}, b={b:.4f}  （真: w=2.0, b=1.0）")

# ── 損失曲線のプロット ────────────────────────────────
plt.figure(figsize=(7, 3))
plt.plot(history, color="#0D4A38")
plt.xlabel("Epoch")
plt.ylabel("MSE Loss")
plt.title("損失曲線（学習の進捗）")
plt.tight_layout()
plt.savefig("loss_curve.png", dpi=120)
plt.show()
出力
Epoch 0 | loss=145.3703 | w=1.3817 | b=0.2110
Epoch 50 | loss=3.4073 | w=1.9798 | b=0.4886
Epoch 100 | loss=3.3649 | w=1.9584 | b=0.6315
Epoch 150 | loss=3.3394 | w=1.9418 | b=0.7426
Epoch 200 | loss=3.3240 | w=1.9289 | b=0.8288
Epoch 250 | loss=3.3147 | w=1.9189 | b=0.8958

最終結果: w=1.9113, b=0.9469 （真: w=2.0, b=1.0）

エポックが進むにつれて損失が下がり、300 エポック後には $w=1.91, b=0.95$ と真の値（2.0, 1.0）に近い値になります。 ただしノイズがあるため、このデータに最も合う値（$w \approx 1.88, b \approx 1.13$、損失 3.30）は真の値と少しずれます。 学習後の損失（約 3.31）が真のパラメータでの損失 3.62 より小さいのはこのためです。

解説動画：直線と損失の地形を同時に見る（約 24 秒）

コード例と同じデータと学習率（$\alpha = 0.01$、300 エポック）で描いています。 最初の数エポックで傾き $w$ がほぼ決まり、その後は細長い谷底に沿って切片 $b$ がゆっくり調整されます。 ★は損失が最小になる点（$w \approx 1.88, b \approx 1.13$）です。

学習率 $\alpha$ の影響

学習率 挙動
0.001 安定しますが収束が遅く、300 エポック後も $b \approx 0.42$ で途中です。エポック数を増やす必要があります
0.01 安定して収束します（勾配降下法のコード例の設定）。300 エポック後は $w \approx 1.91, b \approx 0.95$ です
0.02 収束は速いものの、$w$ が行き過ぎと戻りを繰り返しながら（振動しながら）収束します。300 エポック後は $w \approx 1.89, b \approx 1.09$ です
0.03 以上 発散します（損失が無限大に向かいます）。50 エポック後の損失は、0.03 で約 8 万、0.1 で約 $10^{79}$ です

ハンズオンでは alpha を変えながら損失曲線の形がどう変わるかを観察します。 発散し始める学習率はデータのスケールで変わります。$x$ の値が大きいほど勾配も大きくなるので、同じ学習率でも発散しやすくなります。 この表の値は、このページのデータ（$x$ は 0〜10）で実際に実行した結果です。このデータでは約 0.03 以上で発散します。

このセクションのまとめ

  1. 線形回帰は $\hat{y} = wx + b$ というパラメータ付きの関数です。 学習では、$w, b$ を「データに合う値」に調整します。
  2. 損失関数（MSE）は「予測がどれだけ外れているか」を1つの数値で表す指標です。 この損失を最小化することが学習のゴールになります。
  3. 勾配降下法は「損失の傾き（勾配）を計算して、坂を下る方向にパラメータを少し動かす」 という手続きの繰り返しです。
