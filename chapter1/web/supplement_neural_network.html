前置き

線形回帰では解けない問題がある

前の補足資料（線形回帰）では、線形回帰を「パラメータ付きの関数」として捉え、パラメータをデータから学習する流れを確認しました。 ただし線形回帰（$\hat{y} = \mathbf{W}\mathbf{x} + \mathbf{b}$）には、 直線・平面でしか境界を引けない という根本的な限界があります。 現実の問題の多くはこの限界を超えています。

例：XOR 問題（線形分離不可能）

XOR は「2つの入力が異なるとき 1、同じとき 0」を返す演算です。
4点を散布図に描くと、1本の直線で ○ と × を分けることは不可能 です。
（つまり XOR は、$y = a_1 * x_1 + a_2 * x_2 + b$ の形では表現できない関数です）

$x_1$ $x_2$ $y$（正解）
000 ×
011 ○
101 ○
110 ×

なぜ線形変換では解けないのか？

線形変換の合成もまた線形変換になるので、いくつ重ねても結果は常に「1回の線形変換」と数学的に等価です。
つまり、どれだけ層を増やしても直線的な境界しか表現できません。 この問題を解決するのが 活性化関数（非線形変換） の導入です。

解説動画：隠れ層が平面を曲げて XOR を解く（約 28 秒）

隠れ層 $\mathbf{h} = \mathrm{ReLU}(\mathbf{W}\mathbf{x} + \mathbf{b})$（$\mathbf{W} = \begin{pmatrix} 2 & -1 \\ -1 & 2 \end{pmatrix}$、$\mathbf{b} = (-0.5, -0.5)$）の例です。 線形変換だけでは平面が伸びて傾くだけですが、ReLU で負の部分を折りたたむと、直線 $h_1 + h_2 = 1.25$ で ○ と × を分けられます。

Section 1

ニューラルネットワークの構造

NN は「関数を複雑にするための部品」を積み重ねた構造です。 「線形変換 → 活性化関数（Section 2 で説明）→ 線形変換 → …」 というブロックを繰り返すことで、任意の複雑な入出力関係を近似できます。

2層ニューラルネットワークの構造

入力層（3ノード）→ 隠れ層（3ノード、活性化関数あり）→ 出力層（2ノード）

各部品の役割

ノード 1つの数値を保持する計算単位です。「ニューロン」とも呼びます
$\mathbf{W}$ 重み行列です。前の層の出力を、次の層の入力に変換するパラメータです
$\mathbf{b}$ バイアスベクトルです。変換後の値を平行移動させるパラメータです
$f(\cdot)$ 活性化関数です。線形変換の後に適用し、非線形性を加えます
層（layer） 「線形変換 + 活性化関数」のセットです。NN はこのセットを積み重ねます
2

Section 2

活性化関数：「非線形にする部品」

活性化関数は、各ノードの出力に適用する非線形変換です。 活性化関数がなければ、何層重ねても1回の線形変換と等価になってしまいます。 ここでは代表的な ReLU と Sigmoid の2つを押さえておきましょう。

ReLU

$$ f(x) = \max(0, x) $$

負の値はすべて 0 にし、正の値はそのまま通します。 現代の NN でも広く使われている活性化関数です。
（最初に提案された Transformer でも使われています）

計算が軽く、勾配消失が起きにくいので、深い NN に向いています。

Sigmoid

$$ f(x) = \frac{1}{1 + e^{-x}} $$

任意の実数を 0〜1 の範囲に収めます。 出力を「確率」として解釈したい場合（2値分類の出力層）に使います。

深い層では勾配消失が起きやすいので、隠れ層では ReLU に置き換わりました。

「どの活性化関数を使うか」は設計の選択です。 現代の標準では、隠れ層にはほぼ ReLU（またはその派生形）を使い、出力層は問題に応じて選びます。 大切なのは、「非線形変換が入ることで、関数が複雑な形を表現できる」という点です。

Section 3

順伝播と PyTorch 実装

入力から出力まで順番に計算を進めていく処理を 順伝播（Forward Propagation） と呼びます。 2層NN の場合、数式で書くと次のようになります。

2層NN の順伝播

$$ \mathbf{h} = f\!\left(\mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)}\right) \quad \text{（隠れ層）} $$ $$ \hat{\mathbf{y}} = \mathbf{W}^{(2)}\mathbf{h} + \mathbf{b}^{(2)} \quad \text{（出力層）} $$
$\mathbf{x}$入力ベクトル
$\mathbf{W}^{(l)}, \mathbf{b}^{(l)}$第 $l$ 層の重み行列・バイアスベクトル（学習対象）
$f(\cdot)$活性化関数（ReLU など）
$\mathbf{h}$隠れ層の出力（次の層への入力）
コード例 — PyTorch で 2層NN を実装（nn.Module 最小構成） 
import torch
import torch.nn as nn

# 実行時間: 数秒

# ── モデルの定義 ────────────────────────────────────
class TwoLayerNN(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super().__init__()
        # 第1層: 線形変換
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        # 活性化関数
        self.relu = nn.ReLU()
        # 第2層: 線形変換
        self.fc2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        # 順伝播: 入力 → 隠れ層 → 活性化 → 出力
        h = self.relu(self.fc1(x))   # h = ReLU(W¹x + b¹)
        y = self.fc2(h)              # ŷ = W²h + b²
        return y

# ── インスタンス化 ──────────────────────────────────
model = TwoLayerNN(input_dim=3, hidden_dim=8, output_dim=2)
print(model)

# ── パラメータ数の確認 ──────────────────────────────
total_params = sum(p.numel() for p in model.parameters())
print(f"\n総パラメータ数: {total_params}")

# ── 順伝播のテスト ──────────────────────────────────
x = torch.randn(1, 3)          # バッチサイズ1、入力3次元
output = model(x)
print(f"入力の形状:  {x.shape}")
print(f"出力の形状:  {output.shape}")

forward() メソッドに「どう計算するか」を書くだけです。 逆伝播（勾配計算）は PyTorch が自動で行います。

Section 4

自動微分（autograd）：手で微分しなくていい理由

線形回帰の補足資料では、損失の勾配を手で計算して コードに書き下しました。 NN のパラメータ数は、Section 3 の例のような小さなモデルなら数十個（50 個）ですが、実用的なモデルでは数百万個、LLM では数十億個以上になります。 これほど多くのパラメータについて人手で微分するのは現実的ではありません。

PyTorch の autograd は計算グラフを自動で構築し、 任意のパラメータに対する勾配を計算します。 研究者はモデルの構造（forward()）を書くだけで済み、勾配計算は PyTorch が担当します。

autograd が実現したこと

深層学習の研究・実装が急速に広がった背景の一つに、自動微分フレームワーク（Theano、TensorFlow、PyTorch など）の普及があります。 勾配を手で導出して実装する手間がなくなり、 研究者がモデルの構造設計に集中できるようになりました。

コード例 — autograd による勾配の自動計算 
import torch
import torch.nn as nn

# 実行時間: 数秒

# ── データ（ダミー） ────────────────────────────────
x      = torch.randn(32, 3)   # バッチサイズ32、入力3次元
y_true = torch.randn(32, 2)   # 正解ラベル（2次元）

# ── モデル・損失関数・最適化アルゴリズム ────────────
model     = TwoLayerNN(input_dim=3, hidden_dim=8, output_dim=2)
criterion = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

# ── 1ステップの学習ループ ────────────────────────────
# 1. 順伝播
y_pred = model(x)

# 2. 損失計算
loss = criterion(y_pred, y_true)
print(f"損失: {loss.item():.4f}")

# 3. 勾配を初期化（重要：前ステップの勾配が残るため）
optimizer.zero_grad()

# 4. 逆伝播（autograd が全パラメータの勾配を自動計算）
loss.backward()

# 5. パラメータ更新
optimizer.step()

# 勾配の確認（fc1 の重みに対する勾配）
print(f"fc1.weight の勾配（形状）: {model.fc1.weight.grad.shape}")
print(f"勾配の例: {model.fc1.weight.grad[0, :].detach().numpy().round(4)}")
出力
損失: 1.0823
fc1.weight の勾配（形状）: torch.Size([8, 3])

loss.backward() の1行で、全パラメータの勾配が自動計算されます。 線形回帰で手書きした偏微分式を、ここでは一切書いていません。

PyTorch 学習ループの5ステップ

  1. y_pred = model(x) で、順伝播により予測を計算します
  2. loss = criterion(y_pred, y_true) で、損失を計算します
  3. optimizer.zero_grad() で、前ステップの勾配をリセットします
  4. loss.backward() で逆伝播を行い、autograd が勾配を自動計算します
  5. optimizer.step() で、勾配に従ってパラメータを更新します

この5ステップは PyTorch の学習ループの基本パターンです。 MNIST 分類でも LLM のファインチューニングでも、本質的にはこの繰り返しです。

このセクションのまとめ

  1. 線形回帰の限界：直線で分離できない問題（XOR など）は解けません。 解くには「非線形な関数」が必要です。
  2. ニューラルネットワークは「線形変換 + 活性化関数」のブロックを積み重ねた構造です。 層を深くするほど、複雑な入出力関係を表現できます。
  3. 活性化関数（ReLU など）が非線形性を加えます。活性化関数がなければ、何層重ねても1回の線形変換と等価になります。
  4. autograd が勾配を自動計算します。 forward() を書けば、逆伝播は PyTorch が担当します。
